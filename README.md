# 🌤 Weather App

A modern weather application built with **HTML, CSS and JavaScript**.

Search weather by city, use geolocation, save favorite places and view a 3-day forecast in a clean UI.

---

## 📷 Preview

![Weather App Screenshot](screenshot.png)

---

## ✨ Features

* 🌍 Search cities in different languages
* 📍 Weather for current location
* ⭐ Save favorite cities
* 🕘 Recent searches
* 🌡 Switch between °C / °F
* 📅 3-day weather forecast
* 🎨 Dynamic backgrounds
* 🚩 Country flags
* 🌐 Automatic interface language
* 💾 LocalStorage support
* 📱 Responsive design

---

## 🛠 Technologies

* HTML5
* CSS3
* JavaScript
* Open-Meteo API
* LocalStorage
